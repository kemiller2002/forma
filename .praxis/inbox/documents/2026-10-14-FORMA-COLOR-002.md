## Original requirements and acceptance criteria from GitHub issue #160

## Problem
Forma already tests a subset of semantic contrast pairs, but downstream screens can combine status, selection, charts, links, and surfaces in undocumented ways. Formula-only contrast gates do not guarantee that an application visually communicates task priority or state correctly.

## Requirements
- **FORMA-COLOR-002.1:** Define documented foreground/background pairs and semantic roles for primary/secondary actions, links, selection, notice, warning, danger, success, disabled, pending/unknown, focus, and data-visualization categorical/ordinal marks. State clearly which are application-level extensions, which are supported primitives, and which are not applicable.
- **FORMA-COLOR-002.2:** Define light, dark, forced-colors/high-contrast behavior for each exposed role; any derived colors (`color-mix`, translucent overlays, computed backgrounds) require validation against their *rendered* effective surface, not only source hex values.
- **FORMA-COLOR-002.3:** Ensure critical meaning is available without hue alone (text, icon, pattern, position, border or accessible name as appropriate), including charts and status badges.
- **FORMA-COLOR-002.4:** Add representative executable fixtures for navigation/current state, focus, notices, errors, tables, disabled/unknown states, and charts. Verify normal text at WCAG AA 4.5:1 and meaningful nontext/large-text contrasts at applicable thresholds; do not imply AA compliance proves aesthetic quality.
- **FORMA-COLOR-002.5:** Explicitly document which areas require a product-level palette and hierarchy judgment that cannot be certified by automated contrast tests.

## Acceptance criteria
- Both light and dark fixtures use valid, public Forma roles, and verify rendered/computed colors on real components.
- A fixture exercises grayscale and at least protan/deutan/tritan simulation as screening, forced colors, keyboard focus, and status interpretation without color.
- Regression tests fail on dark-theme foreground/surface mismatches and unrecognizable state meanings; include a test ensuring no false success from a contrast calculation alone.
- Reuse and extend, rather than replace, current contrast, brand, theme, and accessibility checks.
