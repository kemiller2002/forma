## Design principle

When the codemod is unsure whether a `<name` is a tag and a URL attribute follows, it lists the line for review and leaves it unrewritten. It never silently rewrites a location.

## Findings

1. **(high, new)** `mayStartTag` silently rejects real tags in JS/TS/F# (JSX text after `:`, `(`, `)`, `—`, `&amp;`, `/`, `*`, `$5.`; JSX text over 256 characters; HTML in JS/TS strings; F# strings, normal and triple-quoted; multi-line Lit templates), so their href is rewritten and `--check` exits 0. Use the lexer's own state (JSX text, template literal or string: a `<name` is a tag); when a rejected `<name` is followed in the same logical tag by a URL attribute, mask it and report it for review. Test every case; correct CONSUMING-FORMA.md about JSX text.
2. **(medium)** The URL-attribute-selector regex over whole files is quadratic on one long line (`[href=` x50,000: 16.1 s; x100,000: 59.1 s); the regex lexer rescans to the line end for every `/` after an unclosed regex (`{` then `x=/[` x100,000 in .html: 22.9 s). Bound or linearise both; timing tests under 2 s; make the CHANGELOG linear-time claim true or state its bounds.
3. **(low)** A false uncertain tag when the file ends exactly on `}` (`finish >= text.Length`). Treat a group as unclosed only when it has no closing brace; test.

Keep the earlier probes (b1-b8), timings, idempotence, BOM/CRLF and report/write agreement; weaken no tests.
