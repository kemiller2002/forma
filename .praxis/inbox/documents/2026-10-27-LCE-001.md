## Requirements

**LCE-001.1:** Determine what Forma actually guarantees about component layout: text containment, rounded and circular boundaries, padding, minimum and maximum dimensions, wrapping, dynamic content, nesting, connector routing, label placement, responsive behaviour, zoom and accessibility. Do not assume the current components enforce any of these.

**LCE-001.2:** Inventory the components that hold text or content in a bounded region: geometry, sizing, padding, text behaviour, overflow, accessibility and which system owns the layout (Forma, Forma Studio, Limen or the application).

**LCE-001.3:** Build a deterministic F# adversarial layout generator: text length, word structure, typography, character sets (Latin, accented, CJK, right-to-left, emoji, combining), rectangles, rounded rectangles (radius 0 to 50% and elliptical), circles and nested containers. Verify the fonts render the fixtures. Do not equate character count with width.

**LCE-001.4:** Explicitly test rounded-corner and circular containment against the visible boundary, including borders and CSS radius normalisation. Find the transition between passing and failing radius for each padding.

**LCE-001.5:** Separate static validation (before rendering) from rendered-geometry validation (browser measurement). Findings are machine-readable: component, constraint, expected, observed geometry, seed, viewport, typography, computed styles, severity.

**LCE-001.6:** Run the experimental cycle: hypothesis, smallest test, execution, evaluation, minimisation, root cause, smallest reusable fix, challenge the fix, preserve evidence. Use deterministic seeds and bounded batches (100 per family to start).

**LCE-001.7:** Compare the baseline with a constraint-driven correction on identical cases. Do not claim improvement the measurements do not show.

**LCE-001.8:** Evaluate whether Forma Studio prevents, adjusts, warns about or silently accepts invalid layouts, and whether Limen contributes to defects (viewport, zoom, resize, fonts, measurement timing). Change neither without demonstrated cause.

**LCE-001.9:** Retest the Causa causal-analysis diagram with offline synthetic equivalents, and assess the impact on `kemiller2002/indy-init-rehearsal-004` without modifying frozen rehearsal evidence.

**LCE-001.10:** Every confirmed defect becomes a permanent regression fixture with its seed. Preserve accessibility: no shrinking text, no silently hidden essential content. All new layout logic is F#; no new framework, no Python, no inline CSS in product code.
