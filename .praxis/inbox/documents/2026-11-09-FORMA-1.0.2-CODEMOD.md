## Findings

1. **(medium, regression vs 1.0.0)** The tag-context check ends a tag at any `>`, so JSX props containing `=>` or `>` lose location protection (`<a onClick={() => go()} href={"ef-docs"}>`, `<img onLoad={() => x > 1} src="ef-asset" />`). Skip balanced `{...}` and quoted strings when scanning for the tag end.
2. **(low, regression)** Dotfile names are read as class selectors (`".ef-config.json"`, `"/.ef-rc.json"`). A `.ef-` that is a whole quoted string ending in a file extension, or that follows `/`, is a path.
3. **(low)** `--check` and `--dry-run` work line by line while write mode masks the whole file, so multi-line tags are over-reported. Reporting must use the same whole-file masking.
4. **(low, pre-existing)** Markdown reference links (`[d]: /ef-doc`, `[e]: ef-doc`) and Razor `href="@Url.Action("ef-index")"` are rewritten.
5. **(cosmetic)** `docs/COMPONENT-INVENTORY.md` claims the migrator test covers Tabs and Icon because the generator matched fixture strings.

Adversarial tests for each; all prior location and name cases keep passing; idempotent. Version 1.0.2 and a CHANGELOG entry.
