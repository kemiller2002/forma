## Findings

**A (medium) Location-skipping false negatives.** After a full rewrite `--check` exits 0 while these keep `ef-` names:
1. The URL-attribute skip also matches script assignments (`const data = "ef-card"`, `const src = 'ef-button'`, `x.background = "ef-hero"`). Restrict it to HTML/Razor/Vue tag-attribute context.
2. The Markdown link-target skip matches calls such as `handlers[0]("ef-x")`. Restrict it to Markdown files and genuine link syntax.
3. Class selectors followed by host- or file-like suffixes are treated as locations (`.ef-shell.app`, `.ef-tabs.test`, `.ef-icon.svg`, `.ef-card.md`, `.ef-card.map`). A `.` immediately before `ef-` is a class selector.
4. Typed destructuring `const { efTone }: DOMStringMap = el.dataset` is missed.

**B (low)** Non-UTF-8 text files containing tokens (for example a Latin-1 `.css`) are skipped silently. List them as "review" and make `--check` exit 3.

Adversarial tests for every case; prior location/URL cases keep passing; idempotence kept. Version 1.0.1 with a CHANGELOG entry.
