Documentation

Consume Forma from a marketing site

Documentation pages use the same shell. The article stays inside the reading measure, links remain underlined, and the navigation compacts on narrow screens without a script.

Select the theme

Load forma-echelon-marketing.css, which is the brand-neutral marketing layer followed by the Echelon Marketing Theme.

Upgrade deliberately

Change the pinned version, run the installer with --update, review the release notes, and run the site checks before committing.

Keep local CSS local

Local CSS is for identity imagery and content unique to the site. Anything generally useful becomes a Forma capability.
